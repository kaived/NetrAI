# Firebase Setup

Use Firebase only from the backend. The frontend should call FastAPI, and FastAPI should write to Firestore.

```text
Cloudflare Pages frontend
  -> Cloud Run FastAPI
  -> Firebase Firestore cases/{case_id}
```

Do not put Firebase service-account keys in the frontend.

## 1. Create Firebase Project

Create or select a Firebase project, then enable Cloud Firestore.

Use production mode for real deployment. During local development, keep writes server-side through FastAPI.

## 2. Create Firestore Database

Recommended first collection:

```text
cases
```

Each document ID is generated by the backend:

```text
cases/case_YYYYMMDDHHMMSS_xxxxxxxx
```

Stored fields include:

```text
case_id
status
filename
quality
prediction
explanation
report
storage
created_at
updated_at
```

## 3. Local Backend Setup

For local development, create a service-account key from Google Cloud IAM and keep it outside Git.

PowerShell:

```powershell
$env:GOOGLE_APPLICATION_CREDENTIALS="<absolute-path-to-service-account-json>"
```

Then set `backend/.env`:

```text
ENVIRONMENT=development
GCP_PROJECT_ID=your-gcp-project-id
FIREBASE_PROJECT_ID=your-firebase-project-id
FIRESTORE_ENABLED=true
FIRESTORE_CASES_COLLECTION=cases
GCS_ENABLED=false
INFERENCE_MODE=stub
```

You can also use:

```text
FIREBASE_CREDENTIALS_PATH=<absolute-path-to-service-account-json>
```

Prefer `GOOGLE_APPLICATION_CREDENTIALS` for local development because it matches Google Application Default Credentials.

## 4. Cloud Run Setup

In Cloud Run, do not use a JSON key file.

Use the Cloud Run service account and give it access to Firestore.

Backend environment:

```text
ENVIRONMENT=production
GCP_PROJECT_ID=your-gcp-project-id
FIREBASE_PROJECT_ID=your-firebase-project-id
FIRESTORE_ENABLED=true
FIRESTORE_CASES_COLLECTION=cases
INFERENCE_MODE=onnx
MODEL_GCS_URI=gs://your-model-bucket/models/dr_classifier.onnx
```

## 5. First Test

Run backend:

```powershell
cd "<repo-root>\backend"
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8080
```

Then upload an image from the frontend. A document should appear in:

```text
Firestore Database -> cases -> case_...
```

## What MATLAB Does

MATLAB does not connect to Firebase for the first demo.

Use MATLAB for:

```text
dataset indexing
preprocessing experiments
classifier training
metrics
ONNX export
```

Use FastAPI for:

```text
upload handling
quality gate
ONNX inference
Firestore writes
report response
```
