# RetinaScan AI Frontend

React/Vite screening console for the SIH demo and production web UI.

## Local Run

```bash
cd frontend
npm install
npm run dev
```

Create `.env` from `.env.example`:

```text
VITE_API_BASE_URL=http://localhost:8080
```

For the deployed Cloud Run backend:

```text
VITE_API_BASE_URL=https://retinascan-api-58990504584.asia-south1.run.app
```
